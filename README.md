# Bloody Name Tag #

## About ##
The Bloody Name Tag mod adds a **Bloody Name Tag** item which drops when a named mob dies.

The Bloody Name Tag can be used to respawn the named mob.

The revival ritual is as follows:
* Place a cauldron on top of a heat source (Campfire, Lava, Magma Block or Fire)
* Fill the cauldron with water
* Jump into the cauldron to inject it with hearts
* After a bit the cauldron is converted into a **Blood Cauldron**
* Throw a **Bone** and **Rotten Flesh** together with the **Bloody Name Tag** into the **Blood Cauldron**
* Your named friend should now be summoned back!
